Free and Open Source

This project was made to be Open Source and Free to Use. The code for this project is available in its entirety via GitHub. Because of this, filer is open for contributions and suggestions at any time!

Command Line Utility

Packaged with the server build, is a Command Line Utility written in Rust. This utility gives complete control over a user's account (given a token) and allows for easier uploading rather than just using the web view.
